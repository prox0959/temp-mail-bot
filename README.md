# Disposable Temp-Mail Automation Bot

[![Python](https://img.shields.io/badge/Language-Python%20%2F%20Node.js-blue.svg)](#)
[![Security](https://img.shields.io/badge/Privacy-Disposable%20Email-success.svg)](#)
[![Status](https://img.shields.io/badge/Status-Completed-success.svg)](#)

A fast, lightweight automation tool that interacts with disposable temporary mail services (1secmail / GuerrillaMail APIs) to automatically generate burner emails, poll for incoming verification messages, and extract one-time OTP codes.

---

## [EN] Features
* **Dynamic Inbox Generation:** Instantly spawns temporary burner email addresses via REST APIs.
* **Inbox Polling:** Asynchronously checks for new incoming emails at configurable intervals.
* **OTP & Link Extraction:** Uses regex parsing to automatically extract verification links and confirmation codes from incoming messages.

---

## [TR] Özellikler
Geçici e-posta (temp-mail) servisleri üzerinden tek kullanımlık e-posta adresleri oluşturan ve gelen doğrulama kodlarını (OTP) otomatik ayrıştıran otomasyon aracıdır.
* Test ve gizlilik odaklı otomasyon senaryolarında doğrulama süreçlerini hızlandırır.
